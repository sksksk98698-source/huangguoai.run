## 黄金提示词架构标准 (Master Prompt Formula)

```text
[主体描述] + [核心动作与交互] + [空间与光影置景] + [摄影机镜头调度] + [影视质感参数]
```

| 模块构成 | 示例指令要素 | 核心作用 |
| :--- | :--- | :--- |
| **主体描述 (Subject)** | 30岁冷峻商界精英，黑色修身高定西装，利落短发，眼神深沉 | 锁定人物特征与职业气质 |
| **核心动态 (Action)** | 缓步走向落地窗前，抬手看腕表，神色凝重地挂断电话 | 提供明确连贯的物理运动趋势 |
| **环境布景 (Scene)** | 顶层奢华办公室，窗外暴雨倾盆雷电交加，室内冷色调射灯 | 奠定悬疑紧张的情感基调 |
| **机位运镜 (Camera)** | 低角度缓慢向前推镜头（Slow push in），中景切近景特写 | 增强主角压迫感与视觉冲击力 |
| **质感后缀 (Quality)** | 35mm电影镜头，胶片颗粒，逼真皮肤纹理，8k分辨率 | 消除塑料感，提升画面电影质感 |

## 避坑要点与相关指引

- **避免词汇堆砌**：过多的同义词（如 master, ultra realistic, best quality 重复出现）会稀释大模型对关键动作的注意力。
- **正反向搭配**：在使用 Stable Diffusion 或 Midjourney 时，务必配合 [负面提示词清单](/prompts/library/character/) 过滤畸变肢体与多余水印。
- **模型专属性**：不同大模型的权重语法差异极大，请根据工具类型查阅 [模型专属语法手册](/prompts/library/model/)。
