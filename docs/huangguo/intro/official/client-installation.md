1. 在官方主站下载对应架构的安装镜像包：
   - 苹果芯片（M1/M2/M3系列）用户选择：`Apple Silicon 架构 (.dmg)`；
   - 老款英特尔机型选择：`Intel 芯片架构 (.dmg)`；
2. 双击打开下载的 `.dmg` 磁盘镜像，将“黄果短剧”图标拖拽至 `Applications (应用程序)` 文件夹中；
