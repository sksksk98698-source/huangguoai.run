```mermaid
flowchart TD
    Sub["短剧字幕分级策略"]

    Sub --> L2["【二级：核心冲突花字 (Key Punch)】<br>- 亮黄色 / 烈焰红高对比渐变<br>- 字体缩放 1.3 倍跳动弹出<br>- 仅用于‘封城！’、‘退婚！’等爽点词汇"]
    Sub --> L3["【三级：大背景悬念花字】<br>- 顶部半透明粗体，交代时间地点<br>- 如‘五年后·北境极寒前线’"]
```
