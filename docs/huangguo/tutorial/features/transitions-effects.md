## 特效叠加禁忌：莫让特效喧宾夺主

1. **数量控制**：单集 60 秒短剧中，重度闪白和特效转场**不宜超过 3 处**，只用在最核心的剧情高潮点；
2. **黑屏闪烁慎用**：平台算法对全黑屏（Black Screen）时长敏感，超过 0.5 秒的黑屏会被系统判定为“视频故障或画面卡死”影响推流，转场必须使用闪白或快速交叉叠化。
