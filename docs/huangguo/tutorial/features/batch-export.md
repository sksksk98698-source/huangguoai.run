## 自动命名规范与文件归档建议

在点击批量导出时，勾选【启用标准化命名规则】，系统会自动按如下规范批量生成规范文件名：
```
[剧名]_[第XX集]_[画幅]_[分辨率]_[版本号].mp4
范例: DragonKing_EP01_9x16_1080P_Release.mp4
```
这种标准命名方式使得自动化上传脚本或多运营人员协同发布时，绝不会发生“剧集发串、画幅发错”等低级运营事故。
