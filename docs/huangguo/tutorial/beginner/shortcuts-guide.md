## 核心快捷键分类速查表

| 功能分类 | 快捷键 (Windows) | 快捷键 (macOS) | 实际生产用途说明 |
| :--- | :--- | :--- | :--- |
| **工程存盘** | `Ctrl + S` | `Cmd + S` | 强制触发云端工程保存与历史版本快照 |
| **生成与渲染** | `Ctrl + Enter` | `Cmd + Enter` | 焦点在 Prompt 输入框时，直接提交云端渲染队列 |
| **全选批量渲染** | `Ctrl + Shift + R` | `Cmd + Shift + R` | 一键提交当前项目中所有未渲染的分镜头 |
| **时间轴播放/暂停** | `Space (空格键)` | `Space (空格键)` | 随时启停视听监视器播放 |
| **三键飞轮倒放/快进** | `J (倒退) / K (停) / L (快进)` | 同左 | 连续按 L 键实现 2x、4x、8x 倍速快速审片 |
| **单帧精细微调** | `← (左方向键) / → (右方向键)` | 同左 | 逐帧前后移动时间轴光标，捕捉穿帮瑕疵帧 |
| **镜头切割** | `C` | `C` | 在当前光标所在位置一刀切断分镜或音频 |
| **镜头删除** | `Delete / Backspace` | `Delete` | 快速剔除废弃镜头并不留时间轴空白 |
| **复制并新建分镜** | `Ctrl + D` | `Cmd + D` | 复制当前分镜的提示词与人设，用于连贯动作微调 |
| **全屏监视器审阅** | `F` 或 `F11` | `F` | 进入 4K 9:16 无干扰大屏审阅模式 |
