## 角色三视图上传合格与不合格对照清单

为了保证后续视频生成的极高相似度，上传至 [huangguoju.co](https://huangguoju.co/) 资产库的图片必须遵循如下规范：

| 检查维度 | 合格标准 (推荐做法) | 不合格特征 (绝对严禁) |
| :--- | :--- | :--- |
| **面部光照** | 均匀漫反射软光，两侧面颊光比平衡 | 剧烈阴阳脸、强逆光黑脸、闪光灯严重过曝 |
| **发型与遮挡** | 露额头与眉毛，五官轮廓完整展现 | 夸张齐刘海遮眉、墨镜、口罩、碎发大面积遮眼 |
| **面部表情** | 自然微闭嘴唇，双眼平视前方，微表情放松 | 咧嘴大笑露出牙龈、翻白眼、极度愤怒狰狞变形 |
| **图像分辨率** | 1024×1024 以上无压缩高清图 | 压缩糊图、表情包截图、低分辨率模糊老旧照 |

## 道具与场景资产导入规范

除了人物，剧情中反复出现的关键道具和标志性建筑也应当沉淀为资产：

1. **关键道具资产（如战神令、传家翡翠手镯、特定超跑）**：
   - 拍摄或生成透明背景 PNG 图或白底纯净图；
   - 存入【道具库】，设置标签为 `Item_Token`，分镜描述中直接调用该标签，道具外观绝不走样。
2. **固定场景资产（如主角的豪华总裁办公室、萧家大院、阴森地牢）**：
   - 上传一张广角全景图存入【场景库】；
   - 在生成该场景下的各分镜头时，勾选【以此场景为空间背景基准】，渲染器将锁定墙面材质、吊灯款式与地板反光。
