## 避坑与精修建议

1. **避免推理过载导致台词抽象**：R1 在深度思考后有时会输出过于复杂的专业术语，需人工检查台词是否足够通俗接地气。
2. **控制单集信息密度**：单集时长仅 60~80 秒，切勿在单集中塞入超过 2 个核心反转，否则会导致画面剪辑节奏过碎。
3. **保持视觉动作的充沛度**：智斗戏切忌变成“两个角色站在房间里背台词”，必须借助倒酒、撕文件、砸茶杯、摔手机等强视觉动作展现心理攻防。
