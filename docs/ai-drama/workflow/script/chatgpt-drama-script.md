## 阶段一：高一致性角色档案卡（Character Bible）

在开始生成任何台词前，必须先在对话中固化角色设定：

```markdown
【角色档案卡定义指令】：
请为一部都市战神短剧《天龙归来》建立以下核心角色的档案库，并严格保存上下文：
- 主角【萧战】：28岁，北境至尊，外表粗布麻衣沉稳内敛，标志动作是转动大拇指上的青铜龙戒。对爱妻极度温柔，对恶霸言出法随、杀伐果决。
- 女主【苏清雪】：26岁，苏家养女，温婉坚韧，为了病重女儿在苏家忍气吞声，始终坚信萧战会回来。
- 反派岳母【刘艳梅】：52岁，市侩刻薄，贪慕虚荣，口头禅是“我们苏家怎么造了这种孽”。
- 终极反派【韩天宇】：32岁，韩氏财阀大少爷，阴险狠毒，表面慈善家，暗中逼迫苏清雪改嫁。
请确认已完全记忆上述人设，并以“角色卡已建档，请下达剧情任务”回复。
```

## 阶段二：全剧核心节拍表（Beat Sheet）生成

建立好人设后，让模型按照短剧特有的爽点节奏生成大纲：

```markdown
请严格按照短剧“前压后扬、大钩子连小钩子”的节拍规律，为全剧 80 集规划四大阶段节点：
1. 1~10 集：屈辱隐忍期（主角受尽冷眼，反派步步紧逼至生死边缘）
2. 11~30 集：暗中护妻期（主角动用隐秘势力化解危机，但未公开身份）
3. 31~60 集：全面打脸期（反派底牌尽出，主角层层扒皮反杀，中层反派团灭）
4. 61~80 集：终极清算期（全城封道，全球顶级权贵齐聚，主角身份公之于众，恶人终遭报应）
请输出每一集的核心事件与片尾断章钩子（每集一句话）。
```

## 阶段三：工业化标准双栏剧本输出

在生成具体集数时，强制要求输出视觉与听觉分离的格式：

```markdown
请撰写第 3 集脚本，严格按照以下 Markdown 格式输出：

| 镜头编号 | 景别与运镜 | 视觉画面描述（用于AI生图/视频） | 角色与台词/旁白 | 音效与配乐建议 |
| :--- | :--- | :--- | :--- | :--- |
| Cut 01 | 特写，低机位仰拍 | 萧战眼神如寒冰，青铜龙戒闪烁冷芒 | 萧战：“动我妻女者，死。” | 低沉大提琴拉响，杀机四伏 |
| Cut 02 | 中景，俯拍 | 刘艳梅一巴掌扇空，身子踉跄险些摔倒 | 刘艳梅：“你个窝囊废，还敢躲？！” | 滑稽失衡音效转紧迫鼓点 |
| Cut 03 | 特写，推镜头 | 门外突然传来军靴齐步踏地声，震撼走廊 | 传令官（画外音）：“九星战神令到！” | 重低音核爆卡点，剧终断章 |
```

## 常见失误排查与质量提升表

| 常见问题 | 原因分析 | 调优 Prompt 解决方案 |
| :--- | :--- | :--- |
| **角色台词书面化严重** | 模型默认使用书面散文语调 | 增加指令：“全部台词转换为北方现代口语，禁止使用成语和书面连词” |
| **情节进展缓慢拖沓** | 模型擅长长篇铺垫，不适应短剧快节奏 | 增加指令：“删减所有心理活动，所有心理变化必须通过肢体动作和道具展现” |
| **上下文超限导致遗忘** | 对话轮次过多，前序人设被截断 | 每隔 10 集主动让模型复述一遍角色核心目标与当前未解伏笔 |
