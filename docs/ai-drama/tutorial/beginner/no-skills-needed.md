## 零基础创作者必须攻克的三大真实门槛

### 1. 审美与节拍感（非画工）
- 传统时代你需要手绘分镜；AI 时代你只需要看一眼生成的图片，准确判断出**“这个光影够不够狠、人物下巴有没有崩、眼神有没有杀气”**。
- **训练方法**：每天拉片拆解 3 部热播榜短剧的前 3 集，用秒表记录每一个反转和耳光发生的时间戳。

### 2. 结构化自然语言翻译能力（Prompting）
- 告别“帮我画个好看的霸总”这种无效废话。
- 学会用工业参数表达：“30岁冷峻西装男子，低机位仰拍，伦勃朗侧逆光，35mm电影镜头，9:16竖屏”。

### 3. 工具串联工程能力
- 不要试图在一个软件里解决所有事情。
- 学会“剧本用大模型 -> 分镜用 Midjourney -> 视频用可灵 -> 口型用 LivePortrait”的积木式组合。
